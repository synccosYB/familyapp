# Familye App

Extended-family app in Yiddish (RTL) for the Bochner (באכנער, father's side) and Biderman (בידערמאן, mother's side) families.

- `prototype/index.html`: the approved clickable mockup (open in a browser; made-up data, nothing saved). Live: https://familye-proto.sites.tab.bot/
- Real app (Node/TypeScript + Postgres): in progress.

Features: login by side, yahrzeits (Hebrew dates), family trees, Mishnayos & Tehillim lists, simchas with invitations + Google Maps/Waze, cousins directory (husband/wife, address, phones), chat per side.
